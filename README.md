## 🚀 Proyectos destacados

### 💊 Sistema de Gestión de Inventario y Control de Vencimientos

**Estado: ✅ Implementado y en funcionamiento real**

Aplicación de escritorio para Windows desarrollada de manera independiente para una droguería.

**Características principales:**

- Registro de medicamentos mediante códigos de barras.
- Control de cantidades y fechas de vencimiento.
- Dashboard con información del inventario.
- Alertas visuales de medicamentos vencidos y próximos a vencer.
- Registro de entradas y salidas de productos.
- Actualización del inventario al registrar ventas.

**Impacto:**

✅ Seguimiento de más de 3.000 productos.  
✅ Utilizado actualmente por tres personas.  
✅ Reducción de revisiones manuales de vencimientos.  
✅ Mejor control de los medicamentos próximos a vencer.

*Código fuente pendiente de documentar y publicar.*
